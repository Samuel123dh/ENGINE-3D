# ⚙️ ENGINE 3D

### Explore a engenharia por trás dos motores.

O **ENGINE 3D** é um projeto educativo e interativo dedicado ao estudo dos motores automotivos.

O objetivo é apresentar diferentes arquiteturas de motores por meio de modelos tridimensionais, animações mecânicas e explicações técnicas.

## 🔧 Motores disponíveis

- Motores em linha: L3, L4 e L6.
- Motores em V: V6, V8, V10 e V12.
- Motor Boxer.
- Motor em W.
- Motor Rotativo (Wankel).
- Motor Diesel.
- Motor Flex.

## 🚀 Funcionalidades

- Modelos de motores em 3D.
- Rotação dos modelos com o mouse.
- Zoom e visualização de diferentes ângulos.
- Animações dos componentes internos.
- Explicações sobre o funcionamento dos motores.
- Interface responsiva.

## 💻 Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Three.js
- WebGL

## 🎯 Objetivo

Proporcionar uma experiência interativa de aprendizado sobre engenharia mecânica e tecnologia automotiva.
